# webgis
Aplicativo que gera mapa interativo com até 3 camadas, a partir de upload de arquivos tipo ZIP, CSV e XLSX. Apresentado no Trabalho de Conclusão de curso da Pós-Graduação em Saúde Coletiva com área de concentração em Saúde Digital da <a href= https://ufba.br/>Universidade Federal da Bahia</a>
